# ID Card App

Aplicación de tarjeta de identificación estudiantil con interfaz gráfica desarrollada en Python usando Tkinter.

## Características

- Interfaz gráfica moderna con Tkinter
- Generación de código de barras
- Reloj en tiempo real
- Diseño responsivo con foto de usuario
- Estado "ACTIVO" dinámico

## Requisitos

- Python 3.7 o superior
- Pillow (PIL)
- python-barcode

1. Clona este repositorio:

git clone https://github.com/favianpc26/id-card-app.git
